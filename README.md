# Bài 4 - Student Records

**Sinh viên:** Trần Đức Nguyên  
**MSSV:** BIT240173

Ứng dụng React Native (Expo) quản lý sinh viên với đầy đủ CRUD.

## Chức năng
- Trang 1: danh sách sinh viên.
- Trang 2: xem chi tiết sinh viên.
- Trang 3: thêm mới / chỉnh sửa sinh viên.
- Thêm, xem, sửa, xóa (CRUD).
- Lưu dữ liệu local bằng AsyncStorage.
- Avatar từ URL hoặc chọn ảnh trên thiết bị bằng Expo Image Picker.
- Xác nhận trước khi sửa và xóa.
- Tự động hiển thị tiếng Việt / tiếng Anh theo ngôn ngữ thiết bị.
- Kiểm tra dữ liệu bắt buộc, định dạng email và trùng mã sinh viên.

## Chạy project
```bash
npm install
npx expo start
```
